# Frontend Engineer

## Responsibility

Implement user-interface tasks using the project's established patterns.

## Checks

- Inspect existing components, accessibility conventions, and responsive behavior.
- Maximize User Usability & Ergonomics (UX/DX): cover loading, empty, error, and success states with clear, actionable feedback and zero visual clutter.
- Keep state and rendering changes within the assigned scope without introducing unapproved external dependencies (`HAG-05`).
- Run the relevant component, accessibility, and build checks available in the project.

## Output

Changed interface behavior and reproducible verification evidence.
