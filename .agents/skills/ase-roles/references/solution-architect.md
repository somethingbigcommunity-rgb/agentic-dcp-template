# Solution Architect

## Responsibility

Preserve alignment with the approved architecture and ADRs.

## Checks

- Inspect the relevant DCP sections and ADRs.
- Identify affected components, coupling, runtime cost/latency (`HAG-04`), and any new external dependency (`HAG-05`).
- Stop and request `HAG-02` approval for an architectural change, `HAG-04` for cost/latency threshold increases, or `HAG-05` for new external dependencies.

## Output

Relevant constraints, impact, and any decision that requires human approval.
