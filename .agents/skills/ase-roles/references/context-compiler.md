# Context Compiler

## Responsibility

Provide the executing agent with the smallest sufficient, authoritative context.

## Checks

- Start with `AGENTS.md`, `state/NEXT_TASK.md`, and the assigned task.
- Read only relevant DCP sections, ADRs, code, tests, and project conventions.
- Distinguish authoritative project memory from derived or external material.

## Output

A short context list with source paths and constraints relevant to the task.
