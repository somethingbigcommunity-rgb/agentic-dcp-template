# Project Lifecycle Deliverables (`deliverables/`)

This folder holds the stakeholder-facing documents generated across the project lifecycle. Every file in this directory is verified free of internal framework jargon and written in first-person singular (`"I"`).

| Folder | Lifecycle Phase | Contents |
|--------|-----------------|----------|
| `01-discovery/` | Discovery & Baseline | As-Is Discovery & Architecture Baseline PDF and discovery notes |
| `02-planning/` | Planning & Requirements | Executive Project Plan & Roadmap PDF |
| `03-architecture/` | Architecture & Security | Architecture & Security Design Dossier PDF and diagrams |
| `04-verification/` | Verification & Status | Verification, reconciliation, test evidence, and status reports |
| `05-release-and-handover/` | Release & Handover | Delivery Acceptance & Release Report PDF, PR description, and handover notes |
