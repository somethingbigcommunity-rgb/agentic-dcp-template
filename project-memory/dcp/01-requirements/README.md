# 01-requirements

Requirements. Each functional requirement has a `REQ-NNN` ID.

- `brd.md`
- `srs.md`
- `mvp-specification.md` (Lite planning entry point; approved scope links to requirements and stories)
- `functional-requirements.md`
- `non-functional-requirements.md`
- `user-stories/` (one file per `US-NNN`)
