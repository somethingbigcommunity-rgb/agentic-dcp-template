# 04-implementation

Implementation plan and work items: waves, features, user stories, tasks.

Normative section of the DCP: changes require human approval.

Expected documents, created just-in-time when a phase or command needs them:

- `implementation-roadmap.md`
- `waves/`
- `features/`
- `tasks/` (one task file per task, based on [`templates/task-template.md`](../../../templates/task-template.md))
- `prompt-templates/`
- `iteration-protocol.md`

Requirements and User Stories are maintained in `dcp/01-requirements/`. In Lite, `/ase-plan` turns an approved idea into an MVP specification and a minimal Wave → Feature → User Story → Task backlog. Start implementation only with the task assigned in `state/NEXT_TASK.md`, using `/ase-task`.
